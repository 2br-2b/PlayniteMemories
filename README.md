# Playnite Memories

*Keep your friends close, and your memories closer*

This plugin is dedicated to capturing important moments while you're playing your games.

It does this by:
- Capturing screenshots every so often as you're playing;
- Adding F12 as a screenshot button in game libraries besides Steam;
- Copying screenshots over from your Steam screenshots folder into your Playnite folder as you're playing a game.

All of these behaviors can be tweaked in the extension's options
